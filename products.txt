# One product per line. Blank lines and lines starting with "#" are
# ignored. Fields are separated by "|" in this exact order:
#
#   id|name|icon|category|package|pins|price|stock|tags|image|group|variant|description
#
# - id: stable, unique. NEVER reuse or change an id once a product
#   has been sold — order codes reference products by id, and
#   changing an id here will make the decoder show that item as
#   "Removed/unknown item" for existing orders.
# - icon: emoji thumbnail fallback (shown when "image" is blank, or
#   if the image URL fails to load).
# - price: number, no currency symbol (interpreted as PHP/₱).
# - image: optional photo URL or path. Leave blank to just show the
#   emoji icon.
#
# --- VARIANTS (group / variant) ---
# Give several rows the SAME "group" text to show them as ONE shop
# card with a variant picker instead of separate cards. Each row is
# still its own normal product underneath — own id, own price, own
# stock — so the cart, order code, and admin decoder automatically
# track exactly which variant was bought. No other setup needed.
#   - group:   the shared card title, e.g. "5mm LED"
#   - variant: the label shown on that row's picker button, e.g. "Red"
# Leave BOTH blank for an ordinary single-card product (most rows).
#
# - description: everything after the 12th "|", so it may contain
#   commas freely. Keep it on one line (no line breaks).
#
# To add a product: append a new line with a new, unused id.
# To retire a product: delete its line (existing order codes still
# decode correctly — the code carries its own product name/price).
# Then commit and push this file.
