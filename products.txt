# EXE QT Electronics — product catalog
#
# One product per line. Blank lines and lines starting with "#" are
# ignored. Fields are separated by "|" in this exact order:
#
#   id|name|icon|category|package|pins|price|stock|tags|description
#
# - id: stable, unique. NEVER reuse or change an id once a product
#   has been sold — order codes reference products by id, and
#   changing an id here will make the decoder show that item as
#   "Removed/unknown item" for existing orders.
# - icon: a single emoji shown as the product thumbnail.
# - pins: integer pin count.
# - price: number, no currency symbol (interpreted as PHP/₱).
# - stock: integer units currently available.
# - tags: comma-separated, no "|" characters.
# - description: everything after the 9th "|", so it may contain
#   commas freely. Keep it on one line (no line breaks).
#
# To add a product: append a new line with a new, unused id.
# To retire a product: delete its line (existing order codes still
# decode correctly — the code carries its own product name/price).
# Then commit and push this file.
